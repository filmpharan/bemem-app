The design decision

Different personalities. The same job.

มุมเปรียบเทียบ01 Atelier02 Lagoon03 Ion
บุคลิกMinimal premium / warm editorialSoft, welcoming / tactileFuturistic / precise / dark
สีและตัวอักษรIvory + brass · Instrument Serif / ManropeSeafoam + deep teal · ManropeGraphite + signal lime · Space Grotesk
ชั้นวัสดุกระจกแชมเปญบางกับพื้นเซรามิกกระจกน้ำนม ขอบนุ่มเหมือน gelกระจก graphite ขอบเย็นและแสงแคบ
ต้นทุนเมื่อทำ Nativeต่ำ–กลาง: ลด blur แล้วยังมีบุคลิกกลาง: ต้องคุมผิวและเงานุ่มกลาง–สูง: ต้องคุม rim light และ contrast บนพื้นเข้ม
จุดต้องทดสอบSerif เล็ก/บาง และ contrast ขอบปุ่มภาพใต้กระจกและจอความสว่างต่ำแสงจ้าและการเปลี่ยนไปแผ่นรหัสขาว
เหมาะเมื่ออยากเปิดใช้ทุกวันโดยไม่เหนื่อยสายตาอยากให้ bemem เข้าถึงง่ายและเป็นมิตรอยากได้บุคลิกที่จำได้ทันที
