What this direction changes

เสนอ CI, wordmark, typography, พื้นหลัง, วัสดุกริด, ภาพบัตร และ controls ใหม่ทั้งหมด ภาพบัตรเป็นงาน vector/CSS ของบัตรสมมติ ไม่ใช่รูปแบรนด์หรือข้อมูลสมาชิกจริง

รักษาตำแหน่งSearch ใน Header ขวา, Create ขวาบน, Create FAB ซ้ายล่าง, Save ขวาล่าง และ Home FAB ขวาล่างเฉพาะกระเป๋าว่าง
รักษาฟังก์ชันHome ไม่มี drag; Create มีผังร่าง; Saved/Draft และ Save/Discard/Cancel ไม่เปลี่ยน ไม่อ่านหรือเขียน storage จากหน้า Preview

ข้อดี / ข้อควรระวัง

ข้อดี: เข้าถึงง่าย ให้ความรู้สึกเป็นเจ้าของ บัตรแต่ละใบแตกต่างชัดโดยไม่ใช้สีฉูดฉาด

ข้อควรระวัง: ความโปร่งและเงานุ่มต้องทดสอบกับจอสว่างน้อย; หากเพิ่มของตกแต่งมากจะดูเป็นของเล่น

Micro-interactions / proposed, not running

Pressed feedback 90ms, release 160ms และการเปลี่ยนแผ่นข้อมูลไม่เกิน 180ms เป็นค่าทดลองเท่านั้น เปลี่ยนสี/opacity โดยไม่ย้ายปุ่ม ไม่มีการรอ animation ก่อนเปิดรหัส Reduce Motion = 0ms

Android / iOS translation

CSS backdrop blur เป็นภาพจำลองใน Browser ไม่ใช่หลักฐานว่า Native ทำเหมือนกันได้ทันที iOS ประเมิน provider ที่รองรับและ capability checks; Android ใช้ opaque fallback ก่อนจนอนุมัติ provider และทดสอบ frame budget แยก ไม่ animate blur/แสงสะท้อนระหว่างลาก ไม่เพิ่ม dependency ในงานนี้

Draft and persistence

เส้นประคือ Saved origin ของ Coffee Club ภาพ Create เลื่อนบัตรลงหนึ่งช่องเท่ากันทุกธีม Save และปุ่มในภาพเป็นตัวอย่างเท่านั้น ไม่มีการจำลองผลสำเร็จหรือแก้ข้อมูลจริง

QR / CODE 128

One invariant: the code comes first.
พื้นที่รหัสในอนาคตเป็นขาวทึบ รหัสดำ ไม่มี glass, blur หรือแสงสะท้อนทับรหัส/quiet zone
กรอบนี้เป็นข้อกำหนด ไม่ใช่ QR/Barcode ที่สแกนได้ และไม่ใช่ฟีเจอร์ที่สร้างเพิ่ม
