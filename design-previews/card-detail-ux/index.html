bemem / UX exploration / round 01

One card. Three ways to use it.

Pearl Gray — Lagoon Glass · Interactive design only. No wallet connection.

A

Scan First

The code is ready as soon as you open.

Open A on its own ↗

0 extra taps to show Code 128. 1 tap or swipe for QR. The card stays secondary.

B

Card First

Recognize the card, then bring up its code.

Open B on its own ↗

1 tap to show Code 128. 2 taps, or 1 tap + 1 swipe, for QR. More space for card recognition.

C

Compact & Swipe

Identity and code together, controls by your thumb.

Open C on its own ↗

0 extra taps to show Code 128. 1 tap or swipe for QR. Less scrolling; the card artwork is smaller.

Try the same task in each

Switch QR / Code 128, flip Front / Back, scroll to History, close and reopen. Swipe only inside the white code area, away from screen edges. All code graphics are visual placeholders, not scannable codes.

Tap counts start after opening Card Detail. B intentionally adds one explicit “Show code” action. Share and History are marked Coming soon. No choice has been applied to the app.
